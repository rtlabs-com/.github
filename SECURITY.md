# Security Policy

RT-Labs is committed to keeping our products secure. Our process
aligns with **IEC 62443** standards and the **EU Cyber Resilience Act
(CRA)**.

Please do NOT open public GitHub issues, pull requests, or discussions
for security flaws. Public reports compromise user security.

## Where to Report

All security vulnerabilities must be reported according to the [Vulnerability Disclosure Policy](https://rt-labs.com/about-rt-labs/our-policies/#vulnerability_disclosure_policy)
